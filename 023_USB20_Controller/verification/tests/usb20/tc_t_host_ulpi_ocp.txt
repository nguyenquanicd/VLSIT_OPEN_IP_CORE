Test ID and title: t_host_ulpi_ocp - host port power and over-current, host bring-up and RxError over the ULPI wrapper
Priority and rationale: P2. On ULPI, DrvVbus is a PHY register bit (0Ah) and the RxError is an RX CMD; both differ from UTMI+.
Purpose: show the over-current rules of t_fi_ocp with DrvVbus through the PHY register, the host bring-up and transfers at TSCALE 1 over
  ULPI, and the RxError handling of t_host_edge (rxerr) when the error arrives as an RX CMD inside the packet.
Requirements and features: REQ-FUNC-034, 041; REQ-IF-003, 010; REQ-ERR-001; ULPI 1.1 (OTG control register 0Ah, RX CMD). Member
  generators: gen_fi_ocp ulpi (host_ulpi_axim_ts16), gen_host_enum_bulk_dma ts1 (host_ulpi_axim_ts1), gen_host_edge rxerr ulpi (host_ulpi_axim_ts16).
DUT configuration and preconditions: builds host_ulpi_axim_ts16 and host_ulpi_axim_ts1 with the ULPI PHY BFM.
Software flow: the software flow of each member generator (see their headers).
Stimulus: the member operation files with the testlist seeds.
