## Replay / Chạy lại

EN: No baseline was sealed and no cold replay was run (`cold_replay` is not_run). To repeat a run in a clean folder, rebuild with
`scripts/rebuild_all.py` (or the `build.py` command of the record), generate the ops file with the generator named in `testlist.csv`,
and run `scripts/run.py sim ...`; the new run folder holds the same inputs and hashes, and the result lines must equal.

VI: Chưa seal baseline và chưa chạy cold replay. Để lặp lại một run: rebuild, sinh file ops bằng generator ghi trong `testlist.csv`
rồi chạy `scripts/run.py sim ...`; kết quả phải trùng.

## Results and limitations / Kết quả và giới hạn

EN: See `docs/verification_report.md` and the run folders in `runs/`. Compilation: every build passed (records in `build/`). Simulation:
the final regression log is `verification/sim/regress_full_14.log`. Closure: not assessed. Cold replay: not run. Package integrity: not run.
Limitations: host timing at TSCALE > 1 is not accurate (FND-009), the FIFO formal proofs are bounded (depth 28) under reviewed assumptions, the PHY side of ULPI low power is only partly modeled, functional bins are scenario markers, code coverage was measured only for a subset of tests and one seed, the interoperability and compliance items need hardware.

VI: Xem `docs/verification_report.md` và `verification/sim/`. Compile: mọi build đạt. Simulation: log regression cuối là `verification/sim/regress_full_14.log`.
Closure, cold replay, toàn vẹn gói: chưa làm. Giới hạn như trên.

## Resource budget and usage / Ngân sách và mức dùng tài nguyên

EN: `env/resource_budget.json`: one simulation job at a time (R-277), disk stop threshold 2 GiB (lowered from the first value because
the drive is almost full; precompiled-header files of the builds, about 300 MB each, are deleted by `build.py` after a build). Every run has
`resource_usage.json` with the free disk before and after; peak RAM is `not_measured` (no per-process measurement with this tool chain).
Waveforms were not captured (`+out` logs only); formal runs keep the solver traces of failing properties.

VI: Một job simulation mỗi lúc; ngưỡng dừng ổ đĩa 2 GiB; `resource_usage.json` của mỗi run ghi dung lượng trống trước/sau; RAM đỉnh
là `not_measured`; không lưu waveform.

## Troubleshooting / Xử lý lỗi

EN: `STOP: free disk ... below the stop threshold` means the drive is nearly full: free space (the `.gch` files of old builds are regenerable) and rerun.
A run that fails with an unexpected packet or a missing packet is triaged before any check is changed (`docs/bugs.md`); the log of a run is
`runs/<run>/sim.log` (+ulpidbg adds a trace of the ULPI bus). `testbench X.sv not found or ambiguous` means the top name is not unique under `tb/`.
Host scenarios must be generated with the same `ts1`/`ts16` argument as the build they run on. Evidence is never deleted automatically.

VI: `STOP: free disk...` là ổ đĩa gần đầy; lỗi cần phân loại trước khi sửa kiểm tra (xem `docs/bugs.md`); kịch bản host phải sinh cùng tham số
`ts1`/`ts16` với build; evidence không bị tự xóa.

## Reusable generators / Script sinh có thể tái sử dụng

A generation manifest with hashes was not written.
