Changes that loosened, removed or re-targeted an expectation (found by the independent review, `docs/review_ai_2026-11-21.md`): (1) the harness check "write strobes all ones" was removed (r0053; the memory compare stays, no replacement strobe check); (2) the expected-packet time-out was lengthened for 512-byte packets (r0073 to r0075); (3) the suspend expectation became "within 10 ms" (r0096 to r0107); (4) the SOF window at TSCALE 16 was widened to about +-10 percent because of FND-009 (only the TSCALE = 1 host runs keep +-62.5 ns); (5) `timeout` is accepted for a lost response (r0263 to r0266); (6) a poll mask was changed (r0316 to r0319); (7) four assumptions were added to the FIFO formal harness and one cover was lowered (FND-008 closure); (8) seven findings were closed by accepting the observed RTL behavior as the specified one (DEC-042), among them FND-003 (a packet after an AXI error response stays committed). Strengthening changes: chirp row check, TXValid-time mode check, ULPI bus assertions. A human has to confirm every item (R-238).
